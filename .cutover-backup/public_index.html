How it works

One call. One payment.
76 routes live.

Mercury402 implements the x402 payment protocol for deterministic financial data: one endpoint, one price, one USDC payment on Base, one signed JSON response.

01

Discover 76 endpoints

Treasury, FRED, forex, spreads, breakeven inflation, macro intelligence, and composite dashboards are exposed as direct HTTP routes.

02

Receive 402 Payment Required

Your client gets a precise payment descriptor for the requested route, including the exact price and Base USDC settlement details.

03

Pay with USDC on Base

Your agent submits the x402 payment and Mercury verifies settlement before serving data. No API keys or account provisioning.

04

Consume deterministic JSON

The response includes structured data and provenance so automated strategies, dashboards, and agent workflows stay reproducible.
